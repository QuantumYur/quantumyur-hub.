# QuantumYur Cosmic World — Release 10

## Важливо
Цей архів містить **самостійну демонстраційну сторінку** `index.html` та **модуль доповнення** для вашого чинного сайту Release 9. Щоб зберегти всі чинні розділи Release 9, **не замінюйте свій `index.html` файлом з архіву**.

## Рекомендований спосіб: зберегти ваш старий сайт
1. Відкрийте GitHub → `QuantumYur/quantumyur-hub.` → гілка `main`.
2. Завантажте до кореня репозиторію файли `cosmic-world.js`, `cosmic-world.css`, `manifest.webmanifest`, `sw.js` та папку `icons/`.
3. Відкрийте ваш наявний `index.html` у GitHub і натисніть Edit (олівець).
4. Просто перед закривальним `</head>` додайте:

```html
<link rel="stylesheet" href="./cosmic-world.css">
```

5. Просто перед закривальним `</body>` додайте:

```html
<script src="./cosmic-world.js" defer></script>
```

6. Натисніть Commit changes. Файл `index.html` буде таким, як раніше, але із новим розділом World Hub наприкінці основної сторінки.

**Для GitHub Pages** сайт: https://quantumyur.github.io/quantumyur-hub./

## Інший спосіб: повністю нова головна сторінка
Файл `index.html` всередині архіву — окремо створена легша версія сайту з новим інтерфейсом. Замінюйте ним чинний `index.html` лише якщо свідомо бажаєте перейти на новий варіант, бо у ньому немає всіх старих секцій Release 9. Спершу зробіть резервну копію старого `index.html`.

## Можливості
- 10 мов: uk, en, pl, ru, ja, ko, zh, hi, es, pt-BR.
- 365 днів × 6 чотиригодинних відрізків × 10 мов = **21 900 унікальних фонів** протягом невисокосного року; на високосний рік — 21 960.
- Фони генеруються математично, без зберігання тисяч важких фотографій. Оновлення — щохвилинна перевірка початку наступного 4-годинного проміжку. Час — місцевий час пристрою.
- Теми: світла, темна, автоматична; параметри запам'ятовуються на пристрої.
- Прапори, герби, валютні символи країн з відкритого REST Countries. За відсутності мережі — невеликий резервний перелік. Монети в картках **умовні**, посилання ведуть до зображень реальних монет на Wikimedia Commons.
- Курси з Frankfurter API — **довідкові денні**, це не торгові котирування в реальному часі.
- Біржова панель TradingView потребує інтернету і може показувати дані із затримкою; доступні резервні посилання Yahoo Finance та Stooq.
- Адаптація під телефон, планшет, комп'ютер, широкий телевізійний екран; клавіатурний фокус і зменшення анімацій.
- PWA-файли для встановлення на підтримуваних пристроях, із простим кешем локальних файлів. Автономний режим **не** оновлює курси чи біржу.

## Чому зміни не на опублікованому GitHub
GitHub повернув `403 Resource not accessible by integration` під час спроби створити файли. Отже цей пакет підготовлений локально, без жодного перезапису вашого живого сайту.
