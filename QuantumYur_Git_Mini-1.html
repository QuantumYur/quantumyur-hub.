Підключення для редагування

Перегляд публічних файлів працює без входу. Для збереження змін потрібен персональний ключ GitHub з доступом лише до твого репозиторію.

Не підключено

Як отримати ключ

  1. Відкрий GitHub → Fine-grained token.
  2. Вибери власний репозиторій quantumyur-hub..
  3. Надай лише дозвіл Contents: Read and write.
  4. Скопіюй ключ у поле вище.
Важливо: не надсилай ключ нікому, навіть у чат. Програма передає його лише безпосередньо до api.github.com для твоїх дій. Ключ тримається в пам’яті сторінки, а після оновлення потрібно підключитися знову.

Встановити на Android

Відкрий цю програму в Chrome за адресою GitHub Pages. Натисни меню ⋮ → Додати на головний екран або Встановити застосунок.
